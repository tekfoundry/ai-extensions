# Decisions knowledge

Primary owner: `technical-architect`

The technical architect owns the decisions index and architecture decision
records by default. Other specialist roles contribute decisions from their
discipline. The documentation specialist owns cross-links and placement.

## Documents

- [Design baseline migration](design-baseline-migration.md): migration map from
  preserved `_docs/design` documents into `_docs/kb`, human review checklist,
  and deferred documentation debt.

Use this area for:

- accepted architecture decisions
- product, requirements, security, quality, and operations tradeoffs
- decisions that explain why a current behavior exists
- decision records that future plans should preserve
- links from decisions to the docs they affect

Decision records should separate current accepted decisions from open
questions. Keep rejected or historical options only when they explain an
important current tradeoff.
